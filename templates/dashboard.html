1. Search Latency Comparison

Linear length-filtered scanning takes $O(|V|)$ dynamic programming comparisons per word. The Burkhard-Keller metric tree prunes branches using the triangle inequality: $$\text{Edge Distance } k \in [d - N, \; d + N]$$ delivering an average latency of ~2.5 ms ($1.42\times$ to $40\times$ faster than linear scans).

2. Dictionary Coverage vs. Spelling Accuracy

Dictionary coverage indicates the mathematical proportion of submitted tokens that appear in the lexical database. Because Tamil is agglutinative, coverage is supplemented by the sandhi-aware morphological suffix analyzer to prevent false alarms on inflected words.
