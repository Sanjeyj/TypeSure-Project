About TypeSure

TypeSure is a Tamil-language spelling detection and correction tool. It processes Tamil Unicode text locally on a Flask server, compares each token against a curated dictionary, and suggests corrections using a combination of dictionary lookup and string-similarity algorithms.

🎯 Objectives

  • Provide a simple, explainable Tamil spelling assistant.
  • Work entirely offline without paid APIs or cloud services.
  • Demonstrate practical application of NLP algorithms for Indian languages.
  • Help students and general users type Tamil more confidently.

📐 Algorithms Used

1. Unicode NFC Normalization

Tamil text on different systems may store the same character in different binary forms. NFC (Canonical Composition) ensures consistent representation before any comparison is made.

2. Tokenization

The input text is split into spans using regular expressions that respect Tamil Unicode ranges (U+0B80–U+0BFF). Punctuation, spaces, numbers, and English words are separated and preserved — they are never passed to the Tamil spell checker.

3. Dictionary Lookup (O(1) set lookup)

Each Tamil token is checked against an in-memory Python set. Set membership testing is O(1) average case, making the dictionary check very fast even for long texts.

4. Levenshtein Edit Distance

For unknown words, the Wagner–Fischer dynamic-programming algorithm computes the minimum number of single-character edits (insertions, deletions, substitutions) required to transform one string into another. A threshold of ≤ 2 is used to avoid unrelated suggestions.

Example: வணககம் → distance 2 → வணக்கம்

5. Candidate Ranking

Candidates are sorted by edit distance (ascending), then alphabetically as a tiebreaker. Up to 5 suggestions are returned. A length pre-filter eliminates dictionary words whose length differs by more than the threshold before the expensive distance computation.

🗄️ Database Schema

CREATE TABLE checks (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    created_at  TEXT    NOT NULL,   -- ISO-8601 UTC
    word_count  INTEGER NOT NULL,   -- Tamil words scanned
    issue_count INTEGER NOT NULL,   -- potential issues found
    corrections INTEGER NOT NULL DEFAULT 0,
    store_text  INTEGER NOT NULL DEFAULT 0,  -- 1 = user opted in
    input_text  TEXT    -- NULL unless store_text = 1
);

⚠️ Limitations

  • The starter dictionary contains a limited set of common Tamil words and does not cover the full Tamil lexicon (~100,000+ words).
  • The system does not understand Tamil grammar, morphology, or sentence context.
  • Correctly spelled but rare or technical Tamil words may be flagged as unknown.
  • Edit-distance suggestions may occasionally be irrelevant for short words.
  • Tamil compound words and agglutinative forms may not all be present in the dictionary.
  • This prototype is not intended for production use.

🚀 Future Enhancements

  • Integrate a comprehensive Tamil word list (e.g., OLTools, Wiktionary dump).
  • Add morphological analysis to handle Tamil's agglutinative word forms.
  • Implement phonetic similarity (soundex-like) for Tamil consonant clusters.
  • Add context-aware ranking using n-gram language models.
  • Support right-to-left-aware display adjustments for mixed scripts.
  • Browser extension version for system-wide Tamil typing assistance.
