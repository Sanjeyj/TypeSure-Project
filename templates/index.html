Under the Hood

How TypeSure Works

TypeSure combines Unicode normalization, dictionary lookup and edit-distance algorithms to detect potential Tamil spelling issues.

Unicode NFC Normalization

Tamil text from different systems may store the same character in different binary forms. NFC normalization ensures consistent representation before any comparison.

Dictionary Set Lookup

Each Tamil token is checked against an in-memory Python set. Set membership testing is O(1) average case, making dictionary checks near-instant even for long texts.

Levenshtein Edit Distance

For unknown words, the Wagner–Fischer algorithm computes the minimum edits (insertions, deletions, substitutions) needed to match dictionary words, with a threshold of ≤ 2 edits.

🔒

Your Text Stays Private

TypeSure processes all text on its own server. No data is sent to third-party APIs or cloud services. By default, only aggregate statistics (word count, issue count) are stored in the local database — your full text is never saved unless you explicitly opt in.
